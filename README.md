## 📌 Sobre o Projeto

Este repositório foi desenvolvido com o objetivo de consolidar os conceitos de **Modularização e Funções em Python** aplicados à resolução de problemas lógicos e matemáticos. 

A estrutura contém 11 exercícios práticos focados em dividir problemas complexos em pequenos blocos de código reutilizáveis, aplicando conceitos cruciais como:
- Definição de funções (`def`)
- Parâmetros posicionais e nomeados
- Retorno de valores (`return`)
- Lógica de programação estruturada

---

## 📂 Estrutura de Arquivos

O repositório é composto pelos seguintes scripts em Python, cada um resolvendo um problema específico da lista de exercícios:

| Arquivo | Descrição Básica |
| :--- | :--- |
| `Exercício1.py` | Implementação de lógica/função inicial da lista. |

| `Exercício5.py` | Resolução do quinto exercício prático. |

| `Exercício7.py` | Exercício de fixação de sintaxe e escopo. |
| `Exercício8.py` | Lógica aplicada com retorno de dados. |
| `Exercício9.py` | Resolução do nono exercício. |
| `Exercício10.py` | Estrutura de função avançada da lista. |
| `Exercício11.py` | Desafio final utilizando modularização. |
